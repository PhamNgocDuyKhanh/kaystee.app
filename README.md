The official high-performance landing page for **KAYSTEE** — /ˈkeɪ.sti:/ — a text expansion and inline AI browser extension for Microsoft Edge.

KAYSTEE helps you turn repetitive text into memorable shortcuts and expand them instantly while typing, boosting productivity without sacrificing privacy.

---

## ✨ Key Features

### ⚡ Text Expansion & Workflow Automation
- **Instant Expansion:** Sub-millisecond text replacement as you type.
- **Dynamic Template Tokens:** Support for date/time math, caret positioning, and rich formatting.
- **Interactive Prompts:** Form inputs and clipboard substitution dynamically injected into expansions.
- **Command Palette:** Quick-search snippets and execute commands with your `configured shortcut.`
- **Vietnamese IME Friendly:** Flawless composition handling for Telex, VNI, and non-Latin input methods.

### 🤖 AI Capabilities & Privacy
- **Bring Your Own Key (BYOK):** Direct connection to Groq, OpenAI, Anthropic, and Gemini APIs.
- **Local-First Security:** Zero telemetry, no external databases, and 100% offline-ready snippet storage.

### 🎨 Design & Accessibility
- **Raycast-Inspired Dark UI:** Clean, modern, and distraction-free interface.
- **Fully Responsive & Accessible:** Optimized for all viewports with reduced-motion support.

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic Structure)
- **Styling:** Tailwind CSS (via CDN)
- **Icons:** Font Awesome 6.4
- **Scripting:** Vanilla JavaScript (Zero framework overhead)
- **Hosting:** GitHub Pages

> **Note:** The landing page intentionally stays framework-free to maintain ultra-fast load times, simple deployment, and a lightweight codebase.
