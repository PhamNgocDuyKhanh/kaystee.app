FAQ

Questions, answered.

What is SnapType?
SnapType is a browser-based text expander. You create shortcuts for text you use repeatedly, then expand those shortcuts while typing.
Do I need an account?
No account is required for the core browser extension experience.
Can I use AI?
Yes, if the installed version supports the provider you want to use. AI is optional and can be configured separately from your text-expansion shortcuts.
Are my snippets or API keys sent to SnapType?
No. SnapType is local-first with zero telemetry. Your snippets, settings, and API keys are stored locally in your browser and are never sent to a SnapType server.

AI requests are sent directly from your browser to the AI provider you choose. If a snippet uses an AI token such as {{ai:rewrite}}, only the relevant content is sent to that provider.
Do I need an API key to use text expansion?
Text expansion: free, no API key required.
AI features: optional, BYOK.
Where does my data go?
SnapType is designed around local-first browser storage for its core configuration. AI requests, when enabled, may be sent directly to the provider configured by you.
Does it work with Vietnamese typing?
Yes. SnapType supports Vietnamese input methods including Unikey and EVKey with both Telex and VNI.

SnapType pauses snippet detection while you’re composing text and only evaluates shortcuts after the composition is complete, helping prevent accidental triggers and ghost characters.
